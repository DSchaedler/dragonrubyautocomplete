# DragonRuby VS Code Autocomplete

This extension adds generic autocomplete support for DragonRuby Ruby scripts used in the engine.

## AGI Use
This was vibe-coded in one adderall-fueled evening when I couldn't be bothered to learn JavaScript or write out all of the snippets by hand. This doesn't qualify as art to me so I have no qualms about that. If that bothers you don't use it?

## What it provides

- Ruby keyword completion
- DragonRuby-specific globals such as `args`, `gtk`, and `$gtk`
- Generic completions for common engine objects and methods derived from the project source files
- Controller and keyboard key completions for common input patterns
